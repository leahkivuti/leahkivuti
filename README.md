# Leah Kivuti

Data analyst. I use Excel, SQL (PostgreSQL) and Python to clean messy data and turn it into insights people can act on.

## Projects on GitHub

**[safariconnect-sql-analysis](https://github.com/leahkivuti/safariconnect-sql-analysis)** — end-to-end PostgreSQL project on 290 bus bookings: cleaning a damaged Excel export, six business questions with CTEs and window functions, views for a Power BI dashboard.

**[tembo-hotel-sql-cleaning](https://github.com/leahkivuti/tembo-hotel-sql-cleaning)** — cleaning 286 messy hotel bookings: duplicates, four date formats, phone numbers and money fields, then a typed, constrained production table.

**[city-hospital-sql-joins](https://github.com/leahkivuti/city-hospital-sql-joins)** — INNER, LEFT, RIGHT, FULL OUTER and self joins on a small hospital database, with the row counts that show which join drops what.

**[Excel_projects](https://github.com/leahkivuti/Excel_projects)** — Excel analysis and dashboards, starting with a Jumia product performance dashboard (pivot tables, slicers, conditional formatting).
